# Хвостик — веб-версия

Журнал здоровья для собак и кошек: прививки, обработки от паразитов и вес с напоминаниями о следующем сроке. Журнал можно вести вместе с семьёй.

**Сайт:** https://hvostik.daniil-projects.workers.dev

Сайт работает в браузере на телефоне и компьютере, его можно установить на экран телефона как приложение, и он открывается без интернета.

## Что умеет версия 1.1

- Питомцы: добавить, изменить, удалить (кличка, вид, порода, дата рождения, цвет).
- Прививки и обработки: дата, препарат, «напомнить снова через 1 / 3 / 6 / 12 месяцев» или без напоминания.
- Вес: записи и график.
- Главный экран «Что дальше»: просроченное, ближайшие две недели, потом. Кнопки «Готово» (следующий срок считается сам) и «Завтра» (перенос на день).
- **Семейный журнал без входа:** записи сохраняются на сервере; второго владельца или своё второе устройство можно пригласить по ссылке; в истории видно, кто что отметил.
- Ключ восстановления — чтобы открыть журнал на новом телефоне, если старый потерялся.
- Светлая, тёмная тема или как в системе.
- Резервная копия: скачать данные в файл и загрузить обратно.
- Пример с Рексом и Муркой для знакомства (на сервер не отправляется).

## Где хранятся данные

На каждом устройстве — в браузере (localStorage: `hvostik:data:v1` — записи, `hvostik:sync:v1` — ключ журнала и очередь неотправленных изменений). На сервере — в базе Cloudflare D1 `hvostik` (регион Восточная Европа).

Входа и аккаунтов нет. Когда появляется первый свой питомец, сервер заводит журнал и выдаёт устройству секретный ключ. В базе хранится только хэш ключа. Почты, телефонов и имён аккаунтов на сервере нет; есть данные о питомцах и подписи участников, которые они пишут сами («Аня»).

Как подключиться к журналу:
- **приглашение** — одноразовый код на 7 дней, делается в разделе «Семья»;
- **ключ восстановления** — постоянный код журнала; можно заменить на новый, старый перестанет работать.

Если устройство отключили (или журнал удалили), при следующей синхронизации записи с него стираются.

## Как работает синхронизация

У каждой записи (питомец, прививка/обработка, взвешивание) есть время изменения `ts`. Устройство отправляет свои изменения и забирает чужие, начиная с номера, на котором остановилось (`cursor`). Если одну запись поменяли на двух устройствах, побеждает более позднее изменение. Удаление передаётся как метка. Без интернета изменения копятся и уходят, когда связь появится. Синхронизация идёт после каждого изменения, при открытии сайта и раз в 45 секунд, пока он открыт.

## Как устроен проект

```
public/                 сайт
  index.html            каркас страницы и меню
  styles.css            оформление (стиль «Мягче и взрослее»), светлая и тёмная тема
  app.js                логика: данные, синхронизация, расчёт сроков, экраны, формы
  sw.js                 офлайн-режим (запросы /api не кэшируются)
  manifest.webmanifest  описание для установки на телефон
  icon.svg, *.png       иконки
src/worker.js           сервер: журналы, приглашения, синхронизация (адреса /api/*)
migrations/             структура базы данных
scripts/make-icons.mjs  рисует PNG-иконки
wrangler.toml           настройки Cloudflare: сайт, сервер, база
```

### Как считается следующий срок

Для каждой пары «питомец + процедура» (по названию, без учёта регистра) берётся последняя запись. Следующий срок = её дата + выбранный интервал в месяцах. Если нажали «Завтра», срок переносится на завтра, но не раньше планового. Статусы: срок сегодня или прошёл — «просрочено», до 14 дней — «скоро», дальше — «потом».

## Команды

Нужен Node.js. Один раз в папке проекта:

```
npm install
```

Запустить у себя для проверки (сайт и сервер с локальной копией базы):

```
npx wrangler d1 migrations apply hvostik --local
npm run dev
```

Если менялась структура базы (новый файл в `migrations/`), сначала применить её к настоящей базе:

```
npx wrangler d1 migrations apply hvostik --remote
```

Опубликовать изменения на Cloudflare:

```
npm run deploy
```

**После любого изменения файлов в `public/`** увеличьте номер в строке `const CACHE = 'hvostik-v…'` в `public/sw.js`. Иначе у тех, кто установил сайт на телефон, может остаться старая версия.
