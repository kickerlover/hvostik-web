# Хвостик — веб-версия

Журнал здоровья для собак и кошек: прививки, обработки от паразитов и вес с напоминаниями о следующем сроке.

Сайт работает в браузере на телефоне и компьютере, его можно установить на экран телефона как приложение, и он открывается без интернета.

## Что умеет версия 1.0

- Питомцы: добавить, изменить, удалить (кличка, вид, порода, дата рождения, цвет).
- Прививки и обработки: дата, препарат, «напомнить снова через 1 / 3 / 6 / 12 месяцев» или без напоминания.
- Вес: записи и график.
- Главный экран «Что дальше»: просроченное, ближайшие две недели, потом. Кнопки «Готово» (следующий срок считается сам) и «Завтра» (перенос на день).
- Светлая, тёмная тема или как в системе.
- Резервная копия: скачать данные в файл и загрузить обратно.
- Пример с Рексом и Муркой для знакомства, убирается одной кнопкой.

## Где хранятся данные

Только в браузере пользователя (localStorage, ключ `hvostik:data:v1`). Сервера и базы нет, на Cloudflare лежат только файлы сайта. Отсюда ограничения:

- данные одного устройства не видны на другом;
- если очистить данные браузера, записи пропадут, поэтому в настройках есть резервная копия;
- напоминания видны, когда открываешь сайт; push-уведомлений нет.

## Как устроен проект

```
public/                 всё, что публикуется
  index.html            каркас страницы и меню
  styles.css            оформление (стиль «Мягче и взрослее»), светлая и тёмная тема
  app.js                вся логика: данные, расчёт сроков, экраны, формы
  sw.js                 офлайн-режим
  manifest.webmanifest  описание для установки на телефон
  icon.svg, *.png       иконки
scripts/make-icons.mjs  рисует PNG-иконки
wrangler.toml           настройки публикации на Cloudflare
```

Сборки нет: что лежит в `public/`, то и публикуется.

### Как считается следующий срок

Для каждой пары «питомец + процедура» (по названию, без учёта регистра) берётся последняя запись. Следующий срок = её дата + выбранный интервал в месяцах. Если хозяин нажал «Завтра», срок переносится на завтра, но не раньше планового. Статусы: срок сегодня или прошёл — «просрочено», до 14 дней — «скоро», дальше — «потом».

## Команды

Нужен Node.js. Один раз в папке проекта:

```
npm install
```

Опубликовать изменения на Cloudflare:

```
npm run deploy
```

Перерисовать иконки после изменения `scripts/make-icons.mjs`:

```
npm run icons
```

**После любого изменения файлов в `public/`** увеличьте номер в строке `const CACHE = 'hvostik-v1'` в `public/sw.js` (v2, v3…). Иначе у тех, кто установил сайт на телефон, может остаться старая версия.
